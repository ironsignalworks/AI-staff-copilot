# Lost and Found

## Found Items

Any item discovered in a guest room or public hotel area must be reported to the front desk.

The employee receiving the item must record:

- Date and time
- Location where the item was found
- Description of the item
- Name of the employee who found it

## Valuable Items

Cash, passports, identification documents, electronics, and other valuables must be secured immediately and reported to the duty manager.

## Guest Claims

Employees must verify the description of an item before releasing it to a guest.
